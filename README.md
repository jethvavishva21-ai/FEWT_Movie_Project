
# FEWT Movie Project

A movie website built using React and Vite.

## Features
- Browse movies
- Search movies
- View movie details
- Browse TV shows
- Explore movies by language

## Technologies Used
- React
- Vite
- JavaScript
- TMDB API

## Installation

1. Clone the repository.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Create a `.env` file in the project root and add your TMDB access token:

   ```env
   VITE_TMDB_ACCESS_TOKEN=your_token_here
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

## Environment Variables

Do not upload your `.env` file or actual API token to GitHub.
